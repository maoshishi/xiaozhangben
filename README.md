# 小账本 · 记账 Web App

一个纯前端的记账应用，为手机而做：可以“添加到主屏幕”像 App 一样用，**离线可用**，数据只存本机。

- 风格：低饱和、淡紫 + 天蓝、大圆角
- 技术：原生 HTML / CSS / JS，**零依赖、零构建**，图表也是自己画的 SVG
- 数据：`localStorage`，可导出 / 导入 JSON 备份

---

## 一、怎么跑起来

### 方式 1（推荐）：双击启动

双击 `启动.bat`，窗口里会打印两个地址：

```
电脑本机： http://localhost:4173
手机访问： http://192.168.x.x:4173
```

手机和电脑连**同一个 WiFi**，用手机浏览器打开“手机访问”那个地址即可。

> 需要先装 Node.js（https://nodejs.org ，选 LTS）。装完重启命令行。

### 方式 2：命令行

```bash
node scripts/serve.js          # 默认 4173 端口
node scripts/serve.js 8080     # 指定端口
```

### 方式 3：直接双击 `index.html`

也能用（数据照样存本机），但没有“添加到主屏幕”和离线缓存，手机上体验差一些。

---

## 二、装到手机主屏幕

1. 手机浏览器打开上面的局域网地址（或部署后的网址）
2. **iPhone Safari**：分享 → 添加到主屏幕
3. **Android Chrome**：右上角菜单 → 添加到主屏幕 / 安装应用

之后从桌面图标进入，就是全屏无地址栏的 App 样子，断网也能记账。

> 注意：局域网地址的“安装”只在那台电脑开着服务时能打开。想随时随地用，见下面“部署”。

---

## 三、部署到公网（随时随地可用，免费）

任选其一，把整个 `记账` 文件夹传上去即可（纯静态，不需要构建）：

- **GitHub Pages**：新建仓库 → 上传文件 → Settings → Pages → 选 main 分支根目录
- **Vercel / Netlify**：直接拖文件夹进去
- **Cloudflare Pages**：同上

部署得到 `https://xxx.pages.dev` 之类的地址，手机打开后“添加到主屏幕”，就和原生 App 差不多了。

> PWA 的 Service Worker 需要 https（或 localhost）才能生效。

```
│   └── style.css           # 全部样式（配色变量在 :root 顶部，改色很方便）
├── js/
│   ├── icons.js            # 分类定义 + 全套手绘 SVG 图标
│   ├── store.js            # 数据层：增删改查、导入导出、示例数据
│   ├── parse.js            # 智能解析：中文 → 金额/收支/分类/日期
│   ├── ui.js               # Toast、弹层、确认框、金额与日期格式化
│   ├── ledger.js           # 记账页：按月 / 按天分组渲染
│   ├── entry.js            # 记一笔：分类九宫格 + 自绘数字键盘
│   ├── cat.js              # 添加自定义分类（名称 + 图标）
│   ├── budget.js           # 预算设置、超支拦截、检讨书上传 / 查看
│   ├── ai.js               # 智能记账弹层（本地解析 / 大模型）
│   ├── report.js           # 报表：周/月/年 × 收支，折线 + 环形 + 柱状
│   └── app.js              # 导航、记录操作、数据管理、配置
├── icons/                  # PWA 图标（由脚本生成）
├── scripts/
│   ├── serve.js            # 本地静态服务器
│   ├── make-icons.js       # 生成图标 PNG（纯 Node，无依赖）
│   └── test-parse.js       # 解析器命令行测试
└── 启动.bat                # Windows 一键启动
```

## 五、智能记账怎么用

点记账页右下角的机器人按钮，输入一句话：

| 你说 | 解析结果 |
|---|---|
| `午饭花了12块5` | 支出 · 餐饮 · 12.5 · 今天 |
| `昨天打车23` | 支出 · 交通 · 23 · 昨天 |
| `买菜 45.5` | 支出 · 餐饮 · 45.5 · 今天 |
| `发工资8000` | 收入 · 工资 · 8000 · 今天 |
| `收到红包200` | 收入 · 红包 · 200 · 今天 |
| `12月11日 买衣服 199` | 支出 · 购物 · 199 · 12月11日 |
| `看电影 68 晚上8点` | 支出 · 娱乐 · 68 · 20:00 |

解析后会弹出确认卡：可以改收支方向、换分类、改备注，确认后入库。

**能认的东西**：阿拉伯数字和中文数字（十二块五 / 一万二）、元/块/块钱、¥、今天/昨天/前天/大前天/明天、X月X日、X号、早上/中午/下午/晚上/具体几点、20 个支出分类 + 8 个收入分类（衣物归「穿搭」，房租归「租房」）。

**想更聪明**：设置页可以填大模型接口（任何兼容 OpenAI `/chat/completions` 的服务），填了以后优先用大模型解析，失败自动回退本地规则。Key 只存在本机。

## 六、自定义分类

记一笔 → 分类九宫格最后一格 **「添加」** → 弹出「添加主分类」：

- 名称最多 4 个字，不能和同类已有分类重名（支出和收入可以各有一个同名分类）
- 从 34 个图标里点一个（咖啡、蛋糕、药丸、哑铃、音乐、汽车、礼物、手机、相机、钱包、星星、爱心、票券、奖章、绿植……）
- 点「确认」→ 自动取一个低饱和色，插在「其他」前面，并直接选中

自定义分类会跟着数据一起导出 / 导入；智能记账里只要句子里出现分类名（比如「咖啡 32」），就会优先认成它。

## 七、报表怎么看

顶部三个标签切换 **周报 / 月报 / 年报**，下面一排切换 **支出 / 收入**，`‹ 期间 ›` 可以前后翻，点中间的期间文字回到本期。

1. **概览**：本期总额、笔数、日均（年报是月均）
2. **折线图**：周报/月报是按天，年报是按月。点折线上的任意一点，会显示那一天的金额
3. **环形图**：分类占比，低饱和配色 + 白色分隔缝，外圈每个色块都标着**分类名 + 百分比**。点某一圈 → 中间显示该分类的金额和占比；**点中间空白处 → 回到本期总额**
4. **柱状图**：近 5 个周/月/年对比，居中显示、可左右滑动。点哪一根，就跳到那一期并居中，下面同步显示**该期单笔账单 Top 10**（按金额从高到低）

## 八、预算与检讨书

记账页右上角 **靶心图标**（搜索左边）→「开通预算提醒」：

- 填 **今日预计支出** 和 **本月预计支出**（留空或 0 = 不限，至少填一个）
- 打开「开启超支拦截」→ 保存

开启后，记账页「今日支出 / 本月支出」下面会多一行小字：

- 正常：`预算 ¥100 · 剩 ¥2.70`（快花完时变琥珀色）
- 超支：`超 ¥7.30`（红色）

**花超了会怎样**：整个 App 会盖上一张全屏页，其他功能全部点不了，必须先交一份检讨书：

1. 拍一张**手写检讨书**（也可以从相册选），图片会自动压到长边 1000px 再存
2. （选填）写一句反省
3. 点「提交检讨书，继续使用」

交完，检讨书会出现在**当天记录的最前面**，带缩略图，点一下看大图。

几条规则：

- 一份检讨书管**今天**（超了今日预算）和 / 或**这个月**（超了本月预算），提交时按当时超了哪些来算
- 第二天 / 下个月重新算，再超要再写
- 如果超支是「刚才那笔」造成的，全屏页上会出现「撤销刚才那笔」——删掉它就不超支了，可以不写
- 检讨书不算收支，不影响报表合计；会跟数据一起导出 / 导入（图片是压缩后的 base64，一张大概几十到两百 KB）

## 九、数据安全

- 数据在浏览器 `localStorage` 里，**不上传任何服务器**
- 清除浏览器数据 / 卸载浏览器 → 数据会一起消失
- 所以：**发现页 → 导出备份**，会下载一个 `小账本备份-YYYYMMDD.json`
- 换手机：新手机打开应用 → 发现 → 导入数据（自动去重合并）

## 十、开发备注

- 改完 `js/`、`css/` 后手机刷新即可看到（Service Worker 是网络优先，不需要清缓存）
- 发版时把 `sw.js` 里的 `CACHE` 版本号 +1，老缓存会被自动清掉
- 测试解析规则：`node scripts/test-parse.js`
- 重新生成图标：`node scripts/make-icons.js`
- 主色在 `css/style.css` 顶部 `:root`：

```css
--purple: #a99af3;   /* 淡紫 */
--blue: #8fcbf2;     /* 天蓝 */
--grad: linear-gradient(135deg, #b3a6f6 0%, #9dd2f4 100%);
```
